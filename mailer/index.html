choux-mailer

choux-mailer is a small personal automation tool run by a single individual for their own use. It is not a public service and does not accept sign-ups.

It sends plain-text notification emails (for example, task summaries and reports produced by the owner's own automation) from a dedicated sender account to the owner's own email addresses.

It only requests permission to send email. It does not read, modify or delete any mailbox contents.
